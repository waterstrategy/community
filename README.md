# Waterstrategy Community

Welcome to the public community space for the Waterstrategy project. Use this
repository to ask questions, report problems, suggest improvements, and follow
project announcements.

## Where to post

- **Questions and help:** Start a conversation in
  [Discussions](https://github.com/waterstrategy/community/discussions) under
  **Questions**. If Discussions is unavailable, open an issue using the question
  template.
- **Announcements:** Follow the
  [Announcements discussion category](https://github.com/waterstrategy/community/discussions/categories/announcements)
  for project news. Announcements are posted by project maintainers.
- **Problems and actionable requests:** Open an
  [issue](https://github.com/waterstrategy/community/issues/new/choose) and
  choose the problem report or feature request template.

When opening a post, include enough context for others to understand and respond
to it. Please be respectful and avoid sharing private or sensitive information.

Repository administrators: enable GitHub Discussions and add **Questions** and
**Announcements** categories to make the discussion links above available.
